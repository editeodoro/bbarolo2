The tests of nautilus 1.0.6 (github.com/johannesulf/nautilus, MIT licence), run on the copy in
`bbarolo/bayesian/nautilus` (SAMPLER NAUTILUSBB), and in `test_progress_bb.py` those of the line of progress
added by BBarolo. The tests that need h5py (checkpoint files) or dask (`test_pool.py`) are skipped when these
packages are missing.
