# HD 142527: a Bayesian fit of a protoplanetary disk

BBarolo is not only for galaxies: any rotating disk seen in an emission line can be fitted. This example is the
disk of gas and dust around the young star HD 142527, observed in the ¹³CO line with ALMA. The disk rotates at a
few km/s, its channels are 0.08 km/s wide, and it is seen at low inclination. The example fits it with
{doc}`3DFIT <../tasks/3dfit/index>` and `METHOD BAYESIAN`, with only the radii of the rings given: the geometry,
the thickness of the disk, its outer edge and the error of the model are sampled with the rotation and the
dispersion of each ring.

## The data

| | |
|---|---|
| Object | HD 142527, a young Herbig star with a protoplanetary (circumbinary) disk (Perez et al. 2015; Boehler et al. 2017) |
| Data | ¹³CO, ALMA (the header gives the rest frequency of J = 1–0, 110.20 GHz) |
| Cube | 126 × 128 pixels of 0.08 arcsec, 86 channels of 30.5 kHz (0.083 km/s) |
| Beam | 0.46 × 0.38 arcsec |
| Noise | 3.0 × 10⁻³ Jy/beam; the peak is 0.065 Jy/beam |
| Files | [HD142527_13CO.fits](https://github.com/editeodoro/bbarolo2/raw/main/examples/HD142527_13CO.fits) (5.6 MB), [HD142527_3DFIT_BAY.par](https://github.com/editeodoro/bbarolo2/raw/main/examples/HD142527_3DFIT_BAY.par) |

:::

:::{tab-item} Python
:sync: py

```python
from bbarolo import FitMod3D

f = FitMod3D("HD142527_13CO.fits", method="bayesian", radii=[0.65, 1.10, 1.55, 2.00, 2.45])

# Parameters can be set or changed after the constructor: update() returns the task
f.update(specres=0.425,
         free="VROT VDISP PA_SINGLE INC_SINGLE XPOS_SINGLE YPOS_SINGLE VSYS_SINGLE Z0_SINGLE RADMAX FRACERR")
f.update(priors={"vrot": {"name": "uniform", "loc": 0, "scale": 20},    # or ("uniform", 0, 20), or the string
                 "vdisp": {"name": "uniform", "loc": 0, "scale": 10},   # of the parameter file
                 "inc": {"name": "uniform", "loc": 10, "scale": 20},
                 "vsys": {"name": "uniform", "loc": -10, "scale": 20}})
f.get("priors")             # the value of a parameter (as set, or the default)
f.parameters                # all the parameters set so far, a dict
# A new PRIORS replaces the whole value (the parameters it does not name get the default priors);
# f.update(priors=None) restores the default priors of all the parameters

res = f.run(threads=16)     # the sampling, in memory (run() can also change parameters)
res.rings                   # the median rings, with the 68% intervals
res.fitter.print_stats()    # the free parameters, medians and intervals
res.fitter.corner_plot()    # the corner plot (a matplotlib Figure)
res.write()                 # the files of the command line, in output/hd142527/
```
:::
::::

On our server, with 16 cores (16 processes for the sampler), the run takes **41 minutes**: 40.5 minutes of
sampling, with 393 000 likelihoods of a cube of 124 000 voxels (the mask dilated by one beam). The time grows with
the number of free parameters (18 here) and of voxels. The sampler is random, so the numbers below change slightly
from run to run.

## The setup

- **Rings.** {ref}`RADII <par-3dfit-radii>` gives five rings from 0.65 to 2.45 arcsec, 0.45 arcsec apart (about
  one beam). Nothing else about the rings is given: the centre (pixel 63.2, 63.5), the systemic velocity
  (3.7 km/s), the inclination (30°) and the position angle (162°) are first estimated from the data, and are the
  starting point and the centre of the default priors.
- **Free parameters.** VROT and VDISP in each ring; one position angle, inclination, centre, systemic velocity
  and scale height for the whole disk (`_SINGLE`); the outer edge of the gas (`RADMAX`) and a fractional error of
  the model (`FRACERR`): 18 parameters ({ref}`FREE <par-3dfit-free>`).
- **Thickness.** The CO emission of a protoplanetary disk comes from layers above and below the midplane, which
  flare outwards. The model of BBarolo is a layer symmetric about the plane, with a constant scale height: Z0 free
  (between 0 and one beam, the default prior) lets it be thick, as an approximation of the emitting surfaces.
- **Priors.** {ref}`PRIORS <par-3dfit-priors>` sets uniform priors for VROT (0 to 20 km/s), VDISP (0 to 10 km/s),
  INC (10° to 30°) and VSYS (−10 to +10 km/s). The rotation velocities of a disk around a star of a few solar masses
  are a few km/s at a hundred au. The inclination is low, so its prior is kept narrow: at low inclination INC and
  VROT are degenerate. The other priors are the defaults: PA ±15° around the estimate, the centre within
  ±2 beams, Z0 from 0 to one beam, RADMAX within a beam inside the last radius up to the outer edge of the last ring,
  FRACERR log-uniform between 0.001 and 1.
- **Spectral resolution.** {ref}`SPECRES <par-3dfit-specres>` 0.425 channels, the default, is a Gaussian line
  spread function with a FWHM of one channel (see {doc}`../user-guide/spectral-resolution`). The spectral axis is in frequency: the velocities are radio velocities in the LSRK frame of the
  cube.

## Results

| Parameter | Median and 68% interval |
|---|---|
| VROT, 0.65 to 2.45 arcsec | 6.17 (−0.29, +0.35), 4.91 (−0.23, +0.28), 3.78 (−0.18, +0.22), 3.51 (−0.17, +0.20), 3.02 (−0.15, +0.18) km/s |
| VDISP, 0.65 to 2.45 arcsec | 0.40, 0.27, 0.22, 0.21, 0.14 km/s (± 0.01–0.03) |
| INC | 19.1° (−1.1, +1.0) |
| PA | 161.3° ± 0.2° |
| VSYS | 3.737 ± 0.003 km/s |
| Z0 | 0.14 (−0.05, +0.06) arcsec |
| RADMAX | 2.674 arcsec, at the upper limit of its prior |
| FRACERR | 0.18 ± 0.01 |

The rotation velocity falls with radius as $R^{-1/2}$ within the errors (6.17 km/s × (0.65/2.45)$^{1/2}$ = 3.18 km/s,
against 3.02 measured): the Keplerian rotation of a disk around a central mass. The dispersion, 0.1 to 0.4 km/s,
is a few channels at most. The reduced χ² is 1.63 without the model error and 1.20 with it.

At this inclination the data measure the projected velocity $V_\mathrm{rot}\sin i$ much better than $V_\mathrm{rot}$:
VROT of every ring is anti-correlated with INC (correlation coefficient −0.97, the narrow diagonal bands of the
corner plot), and $V_\mathrm{rot}\sin i$ is 2.02 ± 0.03 km/s in the first ring, an error of about 1%, against 5% for
VROT. The rotation velocities, and a dynamical mass from them, are only as good as the inclination, here
constrained by the shape of the disk in a model with a single thick layer.

RADMAX is at the upper limit of its prior, the outer edge of the last ring: the emission extends beyond 2.67 arcsec
(to about 3 arcsec in the position–velocity diagram), so the edge of the gas disk is not measured; to measure it, add
rings beyond. In the centre, the total intensity of the data has a hole, the cavity of the disk, which the model
reproduces only in part: the first ring is at 0.65 arcsec, and the residuals are negative at the edge of the
cavity, where the model has more emission than the data.
