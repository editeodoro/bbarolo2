# Example data

The examples of this documentation use a VLA HI datacube of the nearby spiral galaxy **NGC 2403**,
smoothed to a beam of 60 arcsec: 150 × 150 pixels of 16 arcsec and 62 channels of 5.2 km/s.

Download it from the repository of BBarolo:
[ngc2403.fits](https://github.com/editeodoro/Bbarolo/raw/docs/docs/source/tasks/examples/ngc2403.fits)
(5 MB).

```bash
mkdir bbarolo_examples && cd bbarolo_examples
curl -LO https://github.com/editeodoro/Bbarolo/raw/docs/docs/source/tasks/examples/ngc2403.fits
```
