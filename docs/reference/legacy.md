# BBarolo 1.8 (C++)

BBarolo 1.8 is the last version of the C++ code, and the reference of this pure-Python version. Its
documentation is archived on this site, as it was:

<p><a class="sd-btn sd-btn-primary reference external" href="../legacy/1.8/index.html">The documentation of BBarolo 1.8</a></p>

It describes the C++ executable, its parameters and tasks, and the old Python wrapper pyBBarolo. Most of it
still applies to BBarolo 2, which reads the same parameter files: {doc}`differences` lists what changed.
The code of BBarolo 1.8 is at [github.com/editeodoro/Bbarolo](https://github.com/editeodoro/Bbarolo),
with the example data used by its documentation.
