# Citing BBarolo

If you use BBarolo in your research, please cite the paper that describes it:

> Di Teodoro E. M. & Fraternali F. (2015), *3D-BAROLO: a new 3D algorithm to derive rotation curves
> of galaxies*, MNRAS, 451, 3021.
> [ADS](https://ui.adsabs.harvard.edu/abs/2015MNRAS.451.3021D)

```bibtex
@ARTICLE{2015MNRAS.451.3021D,
   author = {{Di Teodoro}, E.~M. and {Fraternali}, F.},
    title = "{$^{3D}$BAROLO: a new 3D algorithm to derive rotation curves of galaxies}",
  journal = {MNRAS},
     year = 2015,
   volume = 451,
    pages = {3021-3033},
      doi = {10.1093/mnras/stv1213}
}
```
